# Настройка Visual Studio Code

## Рекомендуемые расширения

1. OpenAI Codex
2. PHP Intelephense
3. Laravel Extension Pack
4. Vue - Official
5. Tailwind CSS IntelliSense
6. Docker
7. PostgreSQL
8. GitLens
9. EditorConfig
10. ESLint
11. Prettier

## Рекомендуемый порядок работы

1. Открыть папку проекта.
2. Установить расширение Codex.
3. Войти через аккаунт ChatGPT.
4. Открыть файл `CODEX_PROMPT_START.md`.
5. Скопировать промпт в Codex.
6. Проверять изменения через Git.
7. После каждого этапа делать commit.

## Команды Git

```bash
git init
git add .
git commit -m "Initial CollegePortal planning package"
```

## Если проект будет в WSL

```bash
wsl --install
```

После установки WSL откройте проект через VS Code Remote WSL.
