# Безопасность

## Важно для колледжа

1. Не хранить пароли в открытом виде.
2. Не загружать реальные персональные данные студентов в тестовую среду.
3. Использовать отдельную тестовую базу.
4. Разграничивать роли.
5. Включить журнал действий пользователей.
6. Делать резервные копии.
7. Ограничить доступ к серверу.
8. Использовать HTTPS.
9. Перед реальным внедрением учесть требования к персональным данным.

## Для разработки

- использовать фиктивные данные;
- не публиковать .env;
- не хранить ключи в Git;
- не давать Codex доступ к секретам без необходимости.
