# Installer: локальные правила

- Целевая ОС — Ubuntu Server 24.04 LTS.
- Перед update создавать проверяемый backup; после update выполнять health check.
- Для ошибки обновления сохранять рабочий rollback path и не удалять предыдущую версию до проверки.
- Секреты, сертификаты, backups и runtime `.env` хранить вне Git.
- Release должен быть воспроизводимым и содержать checksums.
- UAT и PROD не устанавливать и не обновлять без отдельного явного разрешения.
- Скрипты должны прекращать работу при ошибке и выдавать понятное русское сообщение.
