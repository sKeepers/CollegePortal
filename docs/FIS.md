# ФИС ГИА / ФИС Приема: подготовка данных MVP

Модуль `/fis` предназначен для подготовки данных к будущему обмену с ФИС ГИА и ФИС Приема.

Важно: текущий MVP не отправляет данные в реальную ФИС. Он выполняет только подготовку, проверку полноты, выгрузку CSV/JSON и ведение статусов пакетов.

## Типы пакетов

- `admission` — пакет ФИС Приема на основе заявлений абитуриентов;
- `gia` — пакет ФИС ГИА на основе экзаменов типа ГИА и данных выпускников.

## Что делает модуль

- создает пакет приема из заявлений за выбранный год;
- создает пакет ГИА из экзаменов/выпускников за выбранный год;
- связывает записи со специальностями и образовательными программами;
- проверяет полноту обязательных данных;
- показывает ошибки проверки;
- выгружает подготовленные данные в CSV и JSON;
- позволяет отметить пакет как `exported` или отправить в архив.

## Статусы пакета

- `draft` — пакет создан, проверка еще не выполнена;
- `validation_failed` — проверка нашла ошибки;
- `ready` — пакет прошел проверку;
- `exported` — пакет вручную отмечен как выгруженный;
- `archived` — пакет закрыт.

## Будущая интеграция

Для реального обмена нужно добавить отдельный слой интеграции:

- настройки подключения;
- официальный формат payload;
- авторизацию/подпись запросов;
- отправку пакета;
- получение статусов обработки;
- журнал обмена и ошибок;
- повторную отправку исправленных записей.

До появления подтвержденного регламента модуль остается зоной контроля качества данных и подготовки выгрузок.

## Импорт заявлений ФИС

Заявления из экспорта ФИС ГИА и Приема загружаются через отдельный connector `fis_admissions`. Реальная отправка в ФИС по-прежнему не выполняется; модуль использует выгрузку как источник данных приемной комиссии.


## Official Outbound Connector Foundation

FIS-API-001 adds a separate official outbound foundation: `/api/fis/outbound/*`, private XML payload storage, local XSD validation, mock transport and safe connection diagnostics. This does not replace the existing inbound FIS XLS/XLSX import. Production send remains blocked until FIS-API-002. See `docs/FIS_OUTBOUND_PACKAGES.md`.
