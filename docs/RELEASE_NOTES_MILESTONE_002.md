# Release Notes: MILESTONE-002

Дата: 03.07.2026.
Окружение проверки: DEV `/srv/college-dev`.

## Общий результат

MILESTONE-002 фиксирует переход CollegePortal к расширенному платформенному MVP. Система уже содержит академические разделы, приемную комиссию, Identity/Digital Pass, проходную, мобильный кабинет, выпускников, дипломы и подготовку данных для ФРДО/ФИС.

## Что реализовано

### Базовая платформа

- Новый Quasar GUI поверх существующего API.
- Dashboard.
- UI Foundation и Design System.
- Layout Guidelines и responsive foundation.
- Глобальный поиск.
- Environment awareness для DEV/TEST/PROD.
- Legacy-интерфейс сохранен.

### Учебный процесс

- Студенты.
- Группы.
- Преподаватели.
- Дисциплины.
- Аудитории.
- Специальности и образовательные программы.
- Расписание.
- Электронный журнал.
- Посещаемость и оценки.
- Учебные планы.
- Нагрузка преподавателей.
- Экзамены и ГИА.
- Отчеты.

### Приемная комиссия

- Раздел `/admissions`.
- Реестр заявлений.
- Фильтры по статусу, программе, специальности, комплектности документов и дате.
- Карточка заявления справа.
- Документы и история заявления.
- Импорт и экспорт CSV.
- Зачисление в студенты через существующий API, если данные позволяют.

### Identity

- Архитектура Identity Domain.
- Digital Identity для студентов и преподавателей.
- QR-пропуска без персональных данных внутри QR.
- Статусы пропуска: active, suspended, revoked, expired.

### QR и проходная

- Раздел `/identity/digital-passes`.
- Раздел `/access/gate`.
- Раздел `/access/reports`.
- Сканирование token.
- Автоматическое определение входа/выхода.
- Защита от слишком быстрого повторного скана.
- Журнал событий проходной.
- Отчеты по проходам.

### Mobile

- Маршрут `/m/student`.
- Маршрут `/m/student/pass`.
- Мобильный layout.
- QR-пропуск студента.
- Блоки расписания, ближайшего занятия, оценок, посещаемости и уведомлений.
- Нижняя мобильная навигация.

### Graduation / Diplomas

- Раздел `/graduation`.
- Выпускники.
- Дипломы.
- Приложения к диплому.
- Статусы диплома.
- Быстрые связи со студентом, группой, экзаменами и ФРДО.

### ФРДО

- Раздел `/frdo`.
- Пакеты ФРДО.
- Записи ФРДО.
- Ошибки проверки полноты.
- Статусы пакета: draft, validation_failed, ready, exported, archived.
- Экспорт CSV/JSON.
- Реальная отправка во ФРДО не реализована.

### ФИС ГИА / ФИС Приема

- Раздел `/fis`.
- Пакеты типов `admission` и `gia`.
- Записи ФИС.
- Ошибки проверки полноты.
- Статусы пакета: draft, validation_failed, ready, exported, archived.
- Экспорт CSV/JSON.
- Реальная отправка в ФИС не реализована.

## Новые API-направления

В рамках последних milestone были добавлены или расширены API для:

- digital identities;
- access scan и access events;
- access reports;
- mobile student cabinet;
- curricula;
- teaching load;
- exams;
- graduation/diplomas;
- FRDO packages;
- FIS packages.

## Исправления UX и инфраструктуры интерфейса

- Новый рабочий layout с таблицей и правой карточкой без наложения.
- Русская локализация таблиц и действий.
- Сохранение размера страницы таблиц в localStorage.
- Более плотные карточки студентов и групп.
- Глобальный поиск с корректным вводом и Ctrl+K/Cmd+K.
- Брендинг колледжа и favicon.
- Индикация окружения в верхней панели.
