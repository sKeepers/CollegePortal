## Что именно добавлено

### DEMO Data Management

Новый раздел:

- `/admin/data-management`

Доступные действия:

- создать демо-данные;
- очистить демо-данные;
- импорт данных;
- экспорт данных.

Очистка запрещена в `production` на backend-уровне. Frontend также отключает кнопку очистки в production.

### Автоматический код

Backend теперь поддерживает автогенерацию для:

- специальностей;
- дисциплин;
- учебных планов;
- групп через автоматическое название группы.

Frontend-формы дисциплин, групп и учебных планов показывают поле кода/названия как read-only. Для ручного изменения нужно нажать кнопку редактирования рядом с полем.

### Фото Person

Реализовано для текущих сущностей:

- студент;
- преподаватель;
- выпускник.

Поддержано:

- загрузка изображения;
- просмотр;
- замена;
- удаление.

Фото используется в:

- карточке студента;
- карточке преподавателя;
- карточке выпускника;
- мобильном кабинете студента;
- QR-пропуске студента;
- рабочем месте проходной.

## Ограничения реализации

- Отдельной сущности `Employee` в текущем MVP нет, поэтому фото сотрудника будет добавлено после реализации полноценного Identity/Person domain.
- Импорт данных в разделе управления данными пока принимает файл и фиксирует факт загрузки; расширенный формат массового импорта нужно согласовать отдельно.
- Очистка демо-данных удаляет только известные тестовые записи из `DemoDataSeeder`, а не произвольные пользовательские данные.
- Фото хранятся в public storage Laravel; перед PROD нужно проверить storage symlink, HTTPS и правила хранения персональных данных.
