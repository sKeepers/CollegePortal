# Документы: пользовательская инструкция

## Сформировать справку об обучении

1. Открыть раздел `Документы`.
2. Выбрать тип `Справка, подтверждающая обучение студента`.
3. Выбрать студента.
4. Нажать `Preview`.
5. Проверить найденные и недостающие данные.
6. Если preview разрешает выпуск, нажать `Сформировать DOCX`.
7. Скачать DOCX из журнала документов.
8. Если PDF доступен на сервере, скачать PDF.
9. После фактической выдачи нажать `Выдать`.

Если PDF недоступен, документ DOCX остается корректным, а PDF не создается фиктивно.
