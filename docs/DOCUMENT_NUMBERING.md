# Нумерация документов

Регистрационный номер формируется по шаблону из `document_types.numbering_pattern`.

Для справки используется:

```text
СПР-{YEAR}-{NUMBER:05}
```

Пример:

```text
СПР-2026-00001
```

Последовательности хранятся в `document_number_sequences` отдельно по типу документа и году. Номер выдается транзакционно при генерации документа. Отмена документа не освобождает номер.

Preview номер не расходует. Повторная печать не меняет регистрационный номер и увеличивает только `reprint_count`.
