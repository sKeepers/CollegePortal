## Как пользоваться

1. `git fetch dev && git merge --ff-only dev/develop`
2. Найди свой раздел **по названию, не по номеру**.
3. Делай «Сейчас», закончив — бери «Дальше», не спрашивая.
4. Заявляй задачу на доске **до** того, как заводишь ветку.
5. **Не оставляй работу незакоммиченной.** Локальная копия владельца общая: `git checkout` соседа стирает несохранённое без следа. За август так трижды терялась готовая работа.
6. Общие документы правь **патчем**, не отправкой файла целиком — так уже сносили чужие разделы.
7. Отправив правку в ствол, **обнови локальную копию** — иначе в ней остаётся «M файл», неотличимый со стороны от несохранённой работы.

## Чат «Проходная, карты и общежитие»

**Сейчас: приём карты на проходной.** Учёт карт сделан и обкатан владельцем, а проход по ним — нет: `scan` понимает только QR. **Протокола CARDDEX для этого не нужно** — нужен разбор входящей строки.

`backend/app/Http/Controllers/Api/AccessGateController.php`, метод `scan`. Строка вида `CP2:…` — это динамический QR, всё остальное подходящей длины — номер карты через `App\Support\Rfid\CardNumber`. **Обязательно включите окно защиты от дублей** `identity.duplicate_scan_window_seconds`: у динамического QR одноразовость своя и окно ему не нужно, а у карты одноразовости нет — считыватель отдаёт номер, пока карта на нём лежит.

Помните про два правила проходной, оба оплачены: **направление чередуется только по разрешённым событиям** — отказ не переставляет человека на другую сторону двери; и **защита от дублей на экране сканирования — по значению кода, а не по времени**.
