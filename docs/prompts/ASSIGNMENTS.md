## Как пользоваться

1. `git fetch dev && git merge --ff-only dev/develop`
2. Найди свой раздел **по названию, не по номеру**.
3. Делай «Сейчас», закончив — бери «Дальше», не спрашивая.
4. Заявляй задачу на доске **до** того, как заводишь ветку.
5. **Не оставляй работу незакоммиченной.** Локальная копия владельца общая: `git checkout` соседа стирает несохранённое без следа. За август так трижды терялась готовая работа.

### Правила загрузки

- **Проба на десяти строках, потом остальные.** Правило оплачено сегодня же: на зачислении контингента проба нашла три дефекта подряд, каждый из которых на 593 строках прошёл бы незамеченным.

## Чат «Учебный процесс 2026-2027»

**Область новая, преемника нет.** Код уже есть — `Curriculum`, `CurriculumItem`, `CurriculumSubject`, `ScheduleEngineController`, `TeachingLoadController`, `JournalLessonController`. Задача не «написать модуль», а **довести существующее до состояния, в котором 1 сентября открывается журнал**.

**Первое, вперёд всего остального: удаление группы уносит с собой студентов.** Найдено координатором 22.08.2026 и проверено на уровне базы стенда.

У `students.group_id` стоит `ON DELETE CASCADE`, и такие же каскады у `journal_lessons`, `schedule_lessons`, `schedule_entries`, `schedule_templates`, `exams` и `teaching_load_items`. Значит `GroupController::destroy`, который делает простой `$group->delete()`, физически сносит всех студентов группы вместе с журналом, расписанием и экзаменами. **Каскад срабатывает в самой базе, мимо Eloquent** — мягкое удаление `students.deleted_at` не участвует, в корзину не попадает ничего, восстанавливать нечем. Пользователь при этом видит один вопрос «Удалить группу?».

**Ещё две вещи из карточки студента, замеченные владельцем 23.08 — делайте вместе с полноэкранной:**
