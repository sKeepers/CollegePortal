# Назначения по чатам

**Обновлено: 10.08.2026, сверено со стволом `04b0099`.**

Этот файл ведёт координирующий чат по указанию владельца. Рабочие чаты его **читают, но не правят** — иначе назначения и отчёт о них перемешаются.

Соседний раздел «Кто чем занят прямо сейчас» в [ACTIVE_WORK.md](../ACTIVE_WORK.md) — наоборот: там пишут рабочие чаты о себе. Два файла, две стороны разговора, конфликтов по строкам нет.

## Как пользоваться

1. **Сначала обнови ствол**, иначе прочитаешь вчерашнее:
   ```bash
   git fetch dev && git merge --ff-only dev/develop
   ```
2. **Найди свой раздел** по названию, которым ты записан на доске в `ACTIVE_WORK.md`. **Не по номеру:** нумерация чатов разъехалась, у владельца и на доске она разная.
3. Делай то, что в «Сейчас». Закончив — бери следующее из «Дальше по очереди», не спрашивая.
4. **Заявляй задачу на доске до того, как заводишь ветку.** Сегодня ветка четыре минуты жила незаявленной, и этого хватило бы, чтобы двое взяли одно и то же. Перед стартом посмотри ещё и `git worktree list` на DEV.
5. Если назначение устарело — задача сделана, файл занят, условие не выполняется — **не выдумывай замену и не бери чужое.** Напиши владельцу, что именно разошлось.

## Чат «Единая карточка человека»

**Область:** контур авторизации — middleware, выдача и проверка токена.

**Сейчас:** [4_SEC_002_COOKIE.md](4_SEC_002_COOKIE.md) — `SEC-002`, токен в httpOnly cookie с CSRF.

**Если план уже показан и ждёт подтверждения — не начинай код, пока владелец не ответит.** Это заложено в задании намеренно: работа затрагивает весь фронтенд и мобильный контур, а выкатка разлогинивает всех.

Не забудь про мобильный контур: сканер на телефоне и личный QR-пропуск ходят тем же входом и требуют secure context. Проверь их в браузере на DEV, а не только тестами.

**Дальше по очереди:**

1. **Маршрут `/legacy` и остаток находки 12.** Старый интерфейс `frontend/src/App.vue` (3588 строк) не мёртв: открывается по адресу `/legacy`, помеченному `public: true`, ссылок на него нет нигде. Это вторая, неподдерживаемая копия интерфейса, ходящая в тот же API. **Разбери, а не удаляй:** что она умеет, кто и когда мог ей пользоваться, чем грозит её существование после перехода на cookie — старый интерфейс может брать токен иначе. Подготовь решение владельцу, само решение за ним. Заодно проверь, не осталось ли ещё мёртвого кода той же природы — это остаток находки 12.

**Не заходить:** `RoleSeeder`, `EnsurePermission`, страницы студентов — за чатом «ФИС ГИА и приёмная комиссия». `AccessReportService`, сидеры демо-данных, движок расписания — за чатом «Учётные записи и демо-данные».
