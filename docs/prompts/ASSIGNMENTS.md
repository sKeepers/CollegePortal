# Назначения по чатам

**Обновлено: 10.08.2026, сверено со стволом `2f1cd5c`.**

Этот файл ведёт координирующий чат по указанию владельца. Рабочие чаты его **читают, но не правят**. Соседний раздел «Кто чем занят прямо сейчас» в [ACTIVE_WORK.md](../ACTIVE_WORK.md) — наоборот: там пишут рабочие чаты о себе.

## Как пользоваться

1. **Сначала обнови ствол:** `git fetch dev && git merge --ff-only dev/develop`
2. **Найди свой раздел** по названию с доски, **не по номеру**: нумерация у владельца и на доске разная.
3. Делай «Сейчас», закончив — бери следующее из «Дальше», не спрашивая.
4. **Заявляй задачу на доске до того, как заводишь ветку.**
5. Назначение разошлось с реальностью — не выдумывай замену и не бери чужое, напиши владельцу.
