# DATA_IMPORT: универсальный импорт реальных данных

Дата: 07.07.2026.
Окружение реализации: DEV `/srv/college-dev`.

## Назначение

Раздел `/admin/import` предназначен для загрузки реальных данных колледжа из CSV/XLSX без прямого вмешательства в базу данных и без использования демо-seeder.

Импорт выполняется только после предварительного просмотра, сопоставления колонок, проверки ошибок и ручного подтверждения.

## Поддерживаемые типы данных

- студенты;
- группы;
- преподаватели;
- дисциплины;
- аудитории;
- абитуриенты.

## Поддерживаемые форматы

- CSV;
- TXT с CSV-структурой;
- XLSX, первый лист файла.

Для CSV автоматически определяется разделитель: `;`, `,` или табуляция.

## Основной процесс

1. Открыть `/admin/import`.
2. Выбрать тип данных.
3. Выбрать режим импорта.
4. Загрузить CSV/XLSX файл.
5. Нажать `Предпросмотр`.
6. Проверить первые строки файла.
7. Проверить или изменить сопоставление колонок.
8. Нажать `Проверить`.
9. Исправить ошибки в файле или сопоставлении, если они есть.
10. Нажать `Подтвердить импорт`.
11. Проверить итоговый отчет и историю импортов.

## Режимы импорта

### Создать новые записи

Создает новые записи. Если строка совпадает с существующей записью по ключу, она считается дублем и попадает в ошибки.

### Обновить существующие по ключу

Ищет запись по ключевым полям и обновляет ее. Если запись не найдена, строка пропускается.

### Пропустить дубли

Создает только новые записи. Если запись уже есть по ключу, строка пропускается без ошибки.

## Ключевые поля

| Тип данных | Ключ |
|---|---|
| Студенты | `email`, если указан |
| Группы | `name` |
| Преподаватели | `email`, если указан |
| Дисциплины | `code`, если указан, иначе `name` |
| Аудитории | `number` + `building` |
| Абитуриенты | `email`, если указан |

## Сопоставление колонок

Система пытается автоматически сопоставить русские и технические названия колонок.

Примеры:

- `Фамилия` -> `last_name`;
- `Имя` -> `first_name`;
- `Группа` -> `group_name`;
- `Образовательная программа` -> `education_program_name`;
- `Телефон` -> `phone`;
- `Дата рождения` -> `birth_date`.

Если автоматическое сопоставление не подошло, пользователь выбирает колонку вручную.

## Связанные данные

Для студентов можно использовать:

- `group_id`;
- или `group_name`.

Для групп и абитуриентов можно использовать:

- `education_program_id`;
- или `education_program_name`.

Если связанная запись не найдена, строка попадет в ошибки проверки.

## Отчет импорта

После проверки или импорта отображаются:

- всего строк;
- создано;
- обновлено;
- пропущено;
- ошибок.

Ошибки хранят номер строки исходного файла и текст причины.

## История импортов

Каждая загрузка сохраняется в `import_jobs`:

- пользователь;
- дата и время;
- тип данных;
- режим;
- имя файла;
- сопоставление колонок;
- preview-строки;
- ошибки проверки;
- итоговый результат.

## Ограничения MVP

- XLSX читается по первому листу файла.
- Нет фоновой очереди для очень больших файлов.
- Нет отката уже подтвержденного импорта через интерфейс.
- Нет шаблонов Excel на скачивание, это следующий полезный этап.
- Для студентов и абитуриентов без email поиск дублей ограничен текущей MVP-логикой.
- Импорт не выполняет очистку данных и не снимает production-защиты.

## Безопасность

- Раздел доступен только пользователям с правом `manage_dictionaries`.
- Production-очистка демо-данных остается запрещенной.
- Реальные персональные данные перед загрузкой нужно согласовать с требованиями безопасности и регламентом обработки ПДн.
