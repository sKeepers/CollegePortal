# Personal Dashboard Layout

## Назначение

`UX-003` добавляет персональную настройку Dashboard для пользователей CollegePortal. Пользователь может менять порядок виджетов, размер, видимость и сохранять свой вариант в базе данных.

Функция работает поверх текущих ролевых Dashboard и не меняет бизнес-логику существующих модулей.

## Backend-модель

Таблица `dashboard_layouts` хранит пользовательские профили расположения.

Поля:

- `user_id` — владелец профиля;
- `dashboard_type` — тип Dashboard: `admin`, `director`, `teacher`, `general`;
- `name` — имя профиля, для MVP используется `Мой Dashboard`;
- `layout` — JSON с расположением виджетов;
- `is_default` — активный профиль пользователя для данного типа Dashboard.

Уникальность: `user_id + dashboard_type + name`.

## API

```text
GET    /api/dashboard/layouts
POST   /api/dashboard/layouts
PUT    /api/dashboard/layouts/{id}
DELETE /api/dashboard/layouts/{id}
POST   /api/dashboard/layouts/{id}/activate
POST   /api/dashboard/layouts/reset
```

Все endpoint находятся под `api.token`. Пользователь может работать только со своими профилями. Изменение профилей других пользователей запрещено даже администратору в рамках этого API.

## Формат layout JSON

```json
{
  "version": 1,
  "widgets": [
    { "id": "stats", "order": 0, "size": "full", "visible": true },
    { "id": "actions", "order": 1, "size": "medium", "visible": true }
  ]
}
```

Размеры:

- `small` — одна колонка;
- `medium` — одна колонка;
- `large` — две колонки на desktop;
- `full` — вся ширина.

На мобильных разрешениях все размеры отображаются в одну колонку, чтобы сохранить стабильный адаптивный порядок.

## Профили Dashboard

Для MVP поддерживаются два профиля:

- `Стандартный` — ролевой порядок из кода;
- `Мой Dashboard` — персональный профиль пользователя из БД.

Если API недоступно или профиль отсутствует, отображается стандартный ролевой Dashboard.

## Drag & drop

Перетаскивание реализовано нативным HTML Drag and Drop без сторонних библиотек. В режиме настройки пользователь может перетащить карточку мышью на позицию другого виджета.

## Скрытие виджетов

В режиме настройки у каждого виджета есть действие `Скрыть`. Скрытые виджеты появляются отдельными кнопками в панели `Скрытые виджеты`; их можно вернуть обратно.

## Правила добавления новых виджетов

1. Добавить виджет в массив `dashboardWidgets` соответствующего ролевого Dashboard.
2. Назначить стабильный `id` без привязки к русскому названию.
3. Добавить `title` для режима настройки.
4. Указать `defaultSize`.
5. Добавить slot с таким же именем, как `id`.
6. Не менять `id` после релиза, иначе сохраненные пользовательские layouts потеряют связь с виджетом.

## Ограничения MVP

- Поддерживается один пользовательский профиль `Мой Dashboard`.
- Изменение высоты виджета не реализовано; меняется только ширина.
- На мобильном разрешении drag/drop визуально доступен, но фактический layout всегда становится одноколоночным.
- Административное управление чужими layout-профилями намеренно не реализовано.
