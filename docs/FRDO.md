# ФРДО: подготовка данных MVP

Модуль `/frdo` предназначен для подготовки данных выпускников и дипломов к будущей интеграции с ФРДО.

Важно: текущий MVP не отправляет данные в реальный ФРДО. Он выполняет только подготовку, проверку полноты, выгрузку CSV/JSON и ведение статусов пакетов.

## Что делает модуль

- создает пакет ФРДО из выпускников за выбранный год;
- связывает записи с выпускником, дипломом, приложением, образовательной программой и специальностью;
- проверяет полноту обязательных данных;
- показывает ошибки валидации по каждой записи;
- выгружает подготовленные данные в CSV и JSON;
- позволяет отметить пакет как `exported` или отправить в архив.

## Статусы пакета

- `draft` — пакет создан, проверка еще не выполнена;
- `validation_failed` — проверка нашла ошибки;
- `ready` — пакет прошел проверку и готов к выгрузке;
- `exported` — пакет вручную отмечен как выгруженный;
- `archived` — пакет закрыт и перенесен в архив.

## Проверки полноты

Проверяются:

- ФИО выпускника;
- дата рождения выпускника, если она есть в данных;
- специальность;
- образовательная программа;
- серия диплома;
- номер диплома;
- регистрационный номер;
- дата выдачи;
- квалификация;
- статус диплома.

## Будущая интеграция

Для реальной интеграции нужно добавить отдельный integration/service layer:

- настройки подключения к ФРДО;
- форматирование payload по официальному формату обмена;
- подписание/авторизацию, если требуется регламентом;
- отправку пакета;
- получение статусов обработки;
- журнал обмена и технических ошибок;
- повторную отправку исправленных записей.

До появления подтвержденного регламента обмена модуль остается зоной контроля качества данных и подготовки выгрузок.
