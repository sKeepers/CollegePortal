# Переменные документов

Технические идентификаторы переменных используются на английском языке.

Основные переменные справки:

- `organization.full_name`;
- `organization.short_name`;
- `organization.address`;
- `organization.phone`;
- `organization.email`;
- `document.number`;
- `document.issue_date`;
- `student.full_name`;
- `student.birth_date`;
- `student.course`;
- `student.group`;
- `student.education_form`;
- `student.funding_type`;
- `student.specialty_code`;
- `student.specialty_name`;
- `student.enrollment_order.number`;
- `student.enrollment_order.date`;
- `student.current_course_order.number`;
- `student.current_course_order.date`;
- `signer.position`;
- `signer.full_name`;
- `verification.url`.

Если обязательная переменная отсутствует, preview показывает недостающее поле и блокирует выпуск.
