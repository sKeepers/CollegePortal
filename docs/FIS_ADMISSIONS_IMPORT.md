# Импорт заявлений из ФИС ГИА и Приема

## Назначение

Специализированный импорт `fis_admissions` загружает заявления абитуриентов из Excel-экспорта ФИС ГИА и Приема в модуль приемной комиссии CollegePortal.

Импорт работает отдельно от универсального CSV/XLSX-импорта и использует `FisAdmissionsImportHandler`.

## Поддерживаемый файл

Поддерживаются `.xls` BIFF8 и `.xlsx`. Для пилотного файла подтверждена структура:

- лист: `Sheet 1`;
- строка заголовков: `1`;
- строк данных: `149`;
- колонок: `24`;
- объединенных ячеек: `0`.

## Идентификация Person

Порядок сопоставления:

1. СНИЛС.
2. Существующее заявление `external_source=fis_admissions` + `external_application_number`.
3. ФИО + дата рождения.
4. Паспорт используется только как дополнительный сигнал и не сохраняется в открытом виде.
5. Неоднозначные совпадения не объединяются автоматически.

Один `Person` может иметь несколько заявлений.

## Идентификация заявления

Заявление определяется по:

- `external_source = fis_admissions`;
- `external_application_number = № заявления`.

Повторный импорт обновляет существующие заявления и не создает дубли.

## Конкурсы

Конкурс ФИС сопоставляется с существующей образовательной программой. Новые специальности и программы автоматически не создаются.

Поддерживаются режимы:

- точное совпадение с программой или специальностью;
- ручное правило для `51.02.02 СКД` → `Социально-культурная деятельность` после 9/11 класса;
- unresolved: строка блокирует apply до ручного решения.

## Персональные данные

В preview, dry-run, audit и логах маскируются:

- СНИЛС;
- паспортные данные;
- адрес.

Паспортные данные из ФИС не сохраняются в открытых полях `applicant_applications`. Пока фиксируется только факт наличия паспорта в `fis_raw_data.passport_present`.

## Dry-run и apply

Apply разрешен только если:

- критических ошибок `0`;
- неоднозначных дублей `0`;
- несопоставленных конкурсов `0`;
- строк `149` для пилотного файла;
- dry-run прошел без блокировок.

## API

- `POST /api/admin/import/fis-admissions/analyze`
- `POST /api/admin/import/fis-admissions/dry-run`
- `POST /api/admin/import/fis-admissions/apply`
- `GET /api/admin/import/fis-admissions/jobs/{id}`

Доступ ограничен административным permission импорта.

## История

История сохраняется в `import_jobs`:

- `source=fis_admissions`;
- `file_hash` SHA-256;
- `mode`;
- `metadata`;
- `warnings`;
- `errors`;
- итоговая статистика.

## Связь с Applicant Documents Registry

Импорт ФИС не создает фиктивные файлы документов. Факт наличия данных из ФИС может использоваться как источник для последующей ручной проверки, но комплектность заявления считается по `applicant_application_documents` и типам из `applicant_document_types`. Административный флаг `documents_provided` не означает полный комплект.
