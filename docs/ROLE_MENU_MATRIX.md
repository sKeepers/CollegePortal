# Role Menu Matrix

## Назначение

Документ фиксирует ожидаемую видимость основных пунктов меню для UAT-002. Frontend-меню не заменяет backend RBAC: API остается источником истины.

## Приемная комиссия

| Роль | Видимость |
| --- | --- |
| `admin` | `Приёмная комиссия` -> `/admissions/foundation` |
| `director` | `Приёмная комиссия` -> `/admissions/foundation` при наличии `admissions.application.view` |
| `admission` | `Приёмная комиссия` -> `/admissions/foundation` |
| `study`, `deputy` | `Приёмная комиссия` -> `/admissions/foundation` в read-only scope |
| `teacher`, `student`, `security` | Пункт не показывается |

Legacy route `/admissions` сохраняется, но не является основным пунктом меню.

## QR и проходная

| Роль | Мой QR-пропуск | Цифровые пропуска | Проходная | Мобильный сканер | Отчеты по проходам |
| --- | --- | --- | --- | --- | --- |
| `admin` | Нет в меню | Да | Да | Да | Да |
| `security` | Нет в меню | Да | Да | Да | Да |
| `student` | Да | Нет | Нет | Нет | Нет |
| `teacher` | Да | Нет | Нет | Нет | Нет |
| `hr` | Да | Нет | Нет | Нет | Нет |
| `admission` | Нет | Нет | Нет | Нет | Нет |

Self-доступ к личному QR использует `view_own_data` или `mobile.student.pass`. Административный реестр требует `digitalpasses.manage`.

## Student Workspace

`student` использует мобильный кабинет `/m/student` для личного расписания, оценок, посещаемости и QR-пропуска. Рабочий маршрут `/journal` и permission `journal.view` доступны преподавателям и сотрудникам учебного процесса, но не student.

## Dashboard

Общий Dashboard должен загружать только те счетчики, на которые у пользователя есть permission:

- `students.view` -> счетчик студентов;
- `groups.view` -> счетчик групп;
- `teachers.view` -> счетчик преподавателей;
- `schedule.view` -> занятия сегодня.

Отсутствие permission не считается ошибкой загрузки.

## System

Системные пункты (`Пользователи`, `Роли`, `Разрешения`, `Настройки`, `Справочники`, `Импорт данных`, `UAT`) показываются только при соответствующих точечных permissions.
