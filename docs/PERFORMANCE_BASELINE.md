# Performance Baseline

## Назначение

Документ фиксирует базовые проверки производительности для UAT-002. Это не нагрузочное тестирование, а минимальный smoke, позволяющий увидеть грубые регрессии интерфейса.

## Целевые страницы

- `/dashboard`;
- `/admissions/foundation`;
- `/people`;
- `/identity/my-pass`;
- `/identity/digital-passes`;
- `/access/gate`;
- `/access/mobile-scanner`;
- `/access/reports`.

## Минимальные ожидания

- страница не должна показывать горизонтальную прокрутку всего viewport;
- меню не должно перекрывать контент;
- таблицы должны прокручиваться внутри своих контейнеров;
- правые карточки не должны накладываться на таблицу;
- Dashboard не должен показывать ошибку частичной загрузки, если причина только в отсутствии permission;
- QR-страницы не должны выводить персональные данные внутри QR payload.
