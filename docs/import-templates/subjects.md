# Шаблон импорта: subjects / Дисциплины

Статус: поддерживается `/admin/import`.

## Обязательные поля

- `Название`

## Рекомендуемые поля

- `Код`
- `Отделение`
- `Описание`

## Ключ обновления

- `Код`, если заполнен.
- Если кода нет, используется `Название`.

## Пример строки

| Название | Код | Отделение | Описание |
| --- | --- | --- | --- |
| Специальность | SUBJ-001 | Фортепиано | Индивидуальные занятия по специальности |

## Частые ошибки

- Одна дисциплина записана разными названиями.
- Код дисциплины не уникален.
- В название добавлены семестр, преподаватель или группа.
- Отделение не совпадает со справочником/принятым написанием.
