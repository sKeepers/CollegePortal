# Шаблон импорта: lesson_times / Сетка звонков

Статус: поддерживается `/admin/import`.

Сетка звонков отвечает на один вопрос: **какому номеру пары какое время
соответствует**. Загрузив её один раз, время в расписании набирать не нужно —
достаточно указать номер пары, и портал подставит начало и конец сам.

## Обязательные поля

- `Номер пары` — целое число от 1 до 12
- `Начало` — «08:30». Принимается и «8:30», и «08:30:00»
- `Окончание` — позже начала

## Необязательные поля

- `Название` — как пара называется на бумаге, например «Первая пара»
- `Действует` — «нет» выключает строку, пустая клетка значит «да»

## Пример файла

```
Номер пары,Начало,Окончание,Название,Действует
1,08:30,10:05,Первая пара,да
2,10:15,11:50,Вторая пара,да
3,12:20,13:55,Третья пара,да
```

## Как это работает дальше

Строка расписания без времени, но с номером пары получает время из сетки.
Время, набранное руками, сетка **не трогает**: перенос занятия и замена
остаются возможными.

Ключ строки — номер пары. Повторная загрузка того же номера в режиме
обновления меняет время, а не заводит вторую строку.

## Порядок загрузки

Как и везде: сначала десять строк, потом остальные. Правило оплачено на
зачислении — ошибка в шапке файла видна на десяти строках и не видна на тысяче.
