# Шаблон импорта: classrooms / Аудитории

Статус: поддерживается `/admin/import`.

## Обязательные поля

- `Номер`

## Рекомендуемые поля

- `Корпус`
- `Этаж`
- `Вместимость`
- `Тип`
- `Описание`

## Ключ обновления

- `Номер` + `Корпус`.

## Пример строки

| Номер | Корпус | Этаж | Вместимость | Тип | Описание |
| --- | --- | ---: | ---: | --- | --- |
| 201 | Главный | 2 | 18 | учебная | Кабинет теоретических дисциплин |

## Частые ошибки

- Номер аудитории содержит корпус внутри одного поля: `Главный-201`.
- Корпус то пустой, то указан по-разному.
- Вместимость записана текстом.
- Тип аудитории не согласован: `класс`, `кабинет`, `учебная аудитория`.
