# Шаблоны пилотного импорта

Эта папка содержит описания файлов для первой загрузки реальных данных колледжа.

## Уже поддерживаются `/admin/import`

- `students.md`
- `groups.md`
- `teachers.md`
- `subjects.md`
- `classrooms.md`
- `admissions.md`

## Подготовительные шаблоны для будущего расширения импорта

- `curricula.md`
- `teaching-load.md`
- `schedule.md`

Подготовительные шаблоны нужны, чтобы собрать и нормализовать реальные данные заранее. Их автоматическая загрузка через `/admin/import` требует отдельной реализации.
