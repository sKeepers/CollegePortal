# Шаблоны пилотного импорта

Эта папка содержит описания файлов для первой загрузки реальных данных колледжа.

## Поддерживаются `/admin/import`

- `students.md`
- `groups.md`
- `teachers.md`
- `subjects.md`
- `classrooms.md`
- `lesson-times.md`
- `admissions.md`
- `curricula.md`
- `teaching-load.md`
- `schedule.md`

После DATA-002 все шаблоны в этой папке можно использовать для пилотной загрузки через единый импорт.
