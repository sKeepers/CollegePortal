# ФИС ГИА: что нажимать

Короткая инструкция для того, кто работает с порталом, а не настраивает его. Технический разбор — в [FIS_TEST_ACCEPTANCE.md](FIS_TEST_ACCEPTANCE.md), туда заглядывать не нужно.

**Делает это администратор портала.** Приёмная комиссия может только посмотреть, что приедет, но не записать.

---

## Часть 1. Загрузить данные из ФИС в портал

### Сначала — два раза проверьте, что готово

**Данные о людях ФИС присылает, а вот куда их положить — нет.** Поэтому до загрузки в портале уже должны быть заведены:

* **образовательные программы** — меню «Справочники» → «Образовательные программы»;
* **группы** — меню «Контингент» → «Группы».

Если их нет, заявления загрузятся, а зачислить людей будет некуда.

### Шаг 1. Возьмите файлы из ФИС

Из личного кабинета ФИС нужно выгрузить:

| Что выгрузить | В каком виде |
| --- | --- |
| Направления подготовки | файл XML |
| Форма обучения | файл XML |
| Источник финансирования | файл XML |
| Статусы заявлений | файл XML |
| Типы документов, удостоверяющих личность | файл XML |
| Сведения об организации | файл XML |
| Заявления | книга Excel |

Сохраните их в одну папку, чтобы не искать по одному.

### Шаг 2. Загрузите справочники

Меню слева → **«ФИС»**. На странице найдите блок **«Данные из ФИС»**.

Для каждого файла XML делайте одно и то же:

1. Нажмите поле **«XML-ответ ФИС»** и выберите файл.
2. Нажмите **«Разобрать»**. Портал покажет, что приедет. **Ничего ещё не записано** — это только просмотр.
3. Посмотрите, что показал. Если всё верно — нажмите **«Применить»**.

**Порядок такой:**

1. **Направления подготовки** — из них получатся специальности.
2. **Форма обучения** — здесь есть особенность, см. ниже.
3. **Источник финансирования** — та же особенность.
4. **Статусы заявлений.**
5. **Типы документов.**
6. **Сведения об организации** — из них портал возьмёт конкурсы.

**Поле «Справочник портала» заполнять больше не нужно.** 18.08.2026 коды справочников ФИС сверены с живым ответом сервиса, и портал теперь узнаёт сам: статусы заявлений, форму обучения, источник финансирования и типы документов. Раньше два последних приходилось выбирать вручную.

Если для какого-то файла портал всё же попросит выбрать справочник — выберите и сообщите, какой это был: значит, его кода в подсказках ещё нет.

### Шаг 3. Загрузите заявления

Заявления — **не XML, а книга Excel**, и загружаются они **в другом разделе**.

Меню слева → **«Импорт данных»**.

1. Выберите файл Excel с заявлениями.
2. Нажмите разбор — портал скажет, что нашёл.
3. Нажмите проверку — портал покажет ошибки, если они есть, и ничего не запишет.
4. Если ошибок нет — нажмите применение.

В файле обязаны быть колонки: **№ заявления, Статус, Дата регистрации, ФИО, Конкурс, Дата рождения, СНИЛС**. Без любой из них портал файл не примет.

### Шаг 4. Зачислите

Из ФИС приходят **заявления**, а не студенты. Чтобы человек стал студентом:

Меню → **«Приём и отчёты» → «Приёмная комиссия»** → откройте заявление → зачислите, указав **группу** и **дату зачисления**.

После этого он появится в разделе «Студенты», и ему можно завести учётную запись.

## Часть 2. Выгрузить данные из портала для ФИС

Портал **не отправляет** данные в ФИС сам — он готовит файл, который вы отправляете сами. Так и задумано.

Меню слева → **«ФИС»**.

1. Нажмите вверху **«+ Пакет приёма»** или **«+ Пакет ГИА»** — смотря что готовите.
2. Заполните название, год и остальные поля, сохраните.
3. Выберите пакет в списке — справа откроется карточка.
4. Нажмите **«Проверить»**. Портал сверит пакет с требованиями ФИС и покажет ошибки, если они есть.
5. Ошибки исправьте в исходных данных и проверьте снова.
6. Когда ошибок нет — нажмите **«CSV»** или **«JSON»**, чтобы скачать файл.
7. Отправив файл в ФИС, нажмите **«Отправлено»** — чтобы было видно, что с этим пакетом уже поработали.
8. Старые пакеты убирайте кнопкой **«Архив»**.

## Если что-то не получилось

| Что видите | Что это значит | Что делать |
| --- | --- | --- |
| «Не указано, в какой справочник портала класть эти записи» | это форма обучения или источник финансирования | заполните поле «Справочник портала» |
| «Список справочников применять некуда» | загрузили оглавление вместо самого справочника | выгрузите из ФИС состав справочника |
| Часть записей вернулась списком «не совпало» | названия в ФИС и в портале расходятся | сверьте эти записи руками |
| Конкурсы не связались с программами | программ ещё нет в портале | заведите программы и загрузите сведения об организации заново |
| «Нельзя зачислить: получены не все обязательные документы» | у заявления отмечены не все документы | отметьте полученные документы в заявлении |
| Кнопка не нажимается, пишет про доступ | вы вошли не администратором | попросите администратора |
| `operation_disabled` при проверке связи с ФИС | связь с ФИС ещё не открыта | на загрузку файлами это не влияет, продолжайте |

---

## Чего сейчас нельзя

**Портал пока не забирает данные из ФИС сам** — только через файлы, которые вы выгружаете из личного кабинета ФИС. Кнопки «Тестовые справочники» и «Сведения организации» на странице ФИС отвечают отказом, и это ожидаемо: связь с ФИС ещё не открыта. **На загрузку файлами это никак не влияет** — всё, что описано выше, работает.

**Портал не отправляет пакеты в ФИС.** Он их готовит и проверяет, отправляете вы сами.
