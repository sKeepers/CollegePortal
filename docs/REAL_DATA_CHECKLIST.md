Дата: 08.07.2026.  
Окружение: DEV `/srv/college-dev`.

## Назначение

Чек-лист помогает собрать реальные Excel/CSV-файлы колледжа, проверить их качество до загрузки и уменьшить количество ошибок при импорте через `/admin/import`.

## Проверка качества до импорта

Перед загрузкой каждого файла проверить:

- первая строка содержит понятные заголовки колонок;
- нет объединенных ячеек;
- нет итоговых строк, шапок внутри таблицы и пустых строк между данными;
- ФИО разделены на `Фамилия`, `Имя`, `Отчество`;
- даты записаны единообразно;
- телефоны не содержат лишних комментариев;
- email записан в отдельной колонке;
- обязательные поля заполнены;
- значения справочников написаны одинаково во всех файлах;
- нет дублей по выбранному ключу обновления.

## Проверка справочников

До импорта нужно сверить значения:

- формы обучения: очная, заочная, очно-заочная;
- формы финансирования: бюджет, договор;
- статусы студентов;
- статусы заявлений;
- виды занятий;
- виды нагрузки;
- виды экзаменов;
- статусы дипломов;
- типы документов.

Если в файле встречается значение, которого нет в `/admin/reference`, сначала согласовать его с ответственным подразделением.

## Что делать с дублями

1. Выбрать ключ обновления до импорта.
2. Найти дубли в Excel через фильтр или сводную таблицу.
3. Для студентов не полагаться только на ФИО: возможны однофамильцы.
4. Для преподавателей использовать email, если он заполнен и уникален.
5. Для групп использовать точное название группы.
6. Для аудиторий использовать номер + корпус.
7. Для дисциплин использовать код, если он есть; иначе нормализованное название.
8. Не удалять спорные строки молча: вынести их в отдельный файл `*_review.xlsx`.

## Что делать с пустыми полями

- Обязательные поля заполнить до загрузки.
- Если значение неизвестно, согласовать допустимое временное значение или оставить строку вне импорта.
- Не писать `нет`, `-`, `?` в обязательные поля без согласования.
- Для необязательных полей пустое значение допустимо.
- Для дат не использовать текстовые комментарии вроде `примерно сентябрь`.

## Минимальная приемка файла перед загрузкой

Файл можно загружать в `/admin/import`, если:

- он открыт и сохранен без ошибок в Excel/LibreOffice;
- заголовки колонок соответствуют шаблону или легко сопоставляются вручную;
- обязательные поля заполнены;
- выбран режим импорта;
- понятен ключ обновления;
- файл содержит сначала небольшой пилотный набор;
- ответственный подтвердил актуальность данных.

## Рекомендованный порядок проверки после импорта

1. Проверить отчет импорта.
2. Открыть историю импортов.
3. Исправить ошибки по строкам и колонкам.
4. Открыть 3-5 случайных карточек созданных записей.
5. Проверить связанные данные.
6. Зафиксировать замечания в UAT/IMPORT-списке.
