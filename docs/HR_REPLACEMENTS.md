# HR Teacher Replacements

## Назначение

Модуль замен связывает кадровые отсутствия преподавателей с Schedule Engine. Автоматической замены нет: пользователь выбирает занятия и преподавателя, затем выполняет preview и apply.

## Flow

1. HR создает или выбирает кадровый период.
2. Система показывает затронутые занятия преподавателя.
3. Для занятия запрашиваются кандидаты на замену.
4. Пользователь выбирает преподавателя.
5. Выполняется preview конфликтов Schedule Engine.
6. Apply вызывает существующий replacement механизм расписания.

## Алгоритм кандидатов

Кандидат ранжируется по признакам:
- ведет ту же дисциплину или имеет нагрузку по дисциплине;
- имеет доступные часы;
- не имеет конфликта расписания;
- из того же подразделения;
- не отсутствует по HR данным;
- имеет подходящую нагрузку.

Причины показываются явно: `same_discipline`, `available_hours`, `schedule_conflict`, `same_department`, `has_load`, `hr_unavailable`.

## Bulk replacements

API `POST /api/hr/replacements/preview` и `POST /api/hr/replacements/apply` принимает массив `items`. Частичные ошибки возвращаются в отчете apply, успешные замены применяются через Schedule Engine.

## Audit

Логируются кадровые периоды, отмены, назначение замен и массовые замены. Preview не меняет БД.
