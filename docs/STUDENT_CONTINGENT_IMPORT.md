# Импорт действующего контингента студентов из DOC

`STUDENT-IMPORT-001` добавляет специализированный источник импорта `student_contingent_doc` для загрузки действующего контингента студентов из служебного DOC-файла.

## Назначение

Импорт предназначен для первичной загрузки действующего контингента без ручного переноса строк из многостраничного документа. Поток безопасный и поэтапный:

1. загрузить DOC на `/admin/import` в блоке `Контингент студентов`;
2. выполнить распознавание;
3. скачать таблицу проверки;
4. выполнить dry-run;
5. исправить спорные строки;
6. применить импорт только после отсутствия блокеров.

Apply реального файла выполняется только после отдельного подтверждения ответственного пользователя.

## Private storage

Исходный DOC и все производные файлы хранятся только в `backend/storage/app/private/imports/students/`:

- `student-contingent-normalized.csv`;
- `student-contingent-review.xlsx`;
- `student-contingent-report.json`.

Эти файлы не коммитятся. В audit и frontend preview не выводятся адреса, телефоны и полные персональные данные.

## Нормализованные поля

Промежуточная таблица содержит:

- источник: `source_page`, `source_section`, `source_row_number`;
- программа: `specialty_code`, `specialty_name`, `profile_name`, `course`, `funding_type`, `group_name_raw`;
- студент: `internal_number`, ФИО, `birth_date`;
- приказы: зачисление, академический отпуск, восстановление;
- служебные поля: `transfer_notes`, `dismissal_notes`, `notes_raw`, `parse_status`, `parse_warnings`.

## Проверки

Dry-run сопоставляет строки с:

- `specialties` по коду специальности;
- `groups` по имени группы;
- `people` по ФИО и дате рождения;
- существующими активными студентами.

Apply блокируется при:

- неоднозначном `Person`;
- неизвестной специальности;
- неизвестной группе;
- некорректной дате рождения;
- конфликте с активным студентом;
- критической ошибке парсинга или строке `review_required`.

## Создаваемые данные

При apply создаются или обновляются:

- `people` как единый источник общей персоны;
- `students` с привязкой к группе;
- `student_status_histories` для статусов и приказов.

Строки не объединяются автоматически только по ФИО, если найдено несколько кандидатов Person.

## Permissions

- `students.import_contingent` — upload/analyze/dry-run;
- `students.import_contingent_review` — просмотр job и скачивание review XLSX;
- `students.import_contingent_apply` — подтверждение apply;
- `students.view_private_contacts` — доступ к приватным контактам в будущих интерфейсах.

## Ограничения MVP

- Legacy binary DOC без извлекаемого текста может потребовать конвертации в текстовый DOC/TXT до загрузки.
- Импорт не исправляет автоматически ошибки исходника.
- Отчет в интерфейсе намеренно обезличен.
