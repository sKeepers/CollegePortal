# Бот MAX для уведомлений

Что нужно сделать владельцу, чтобы портал мог присылать уведомления в MAX. Работы в мессенджере — пять минут.

**Это не вход через MAX.** Входа для стороннего сайта у MAX не существует: официальное API описывает ботов и mini-apps, и только. Разбор — [AUTH_005_PLAN.md](AUTH_005_PLAN.md). Бот нужен для другого — чтобы портал мог **написать человеку** о занятии, экзамене или оценке.

## Почему именно MAX, а не Telegram

Проверено 11.08.2026 прямо с боевого сервера: адреса Telegram доступны через один, и не доступны через два других — `149.154.167.220` отвечает, `149.154.166.110` и `149.154.175.50` молчат. DNS отдаёт их по кругу, поэтому отправка через Telegram работала бы через раз. `dev.max.ru` с того же сервера отвечает нормально.

**На вход через Telegram это не влияет:** подпись проверяется на нашем сервере, наружу он не ходит вовсе. Разделение получается такое: **вход — Telegram, уведомления — MAX.**

## Шаги

### 1. Выбрать аккаунт

То же правило, что и с телеграмным ботом: заводите с номера, который останется у колледжа. Бот принадлежит создавшему аккаунту.

### 2. Создать бота

1. В MAX найти в поиске **`@MasterBot`** — это официальный бот для создания ботов, аналог BotFather.
2. Отправить `/create`.
3. Ввести **имя пользователя** — латиницей, от 11 до 60 символов, обязательно заканчивается на `bot`. Например: `skki_portal_bot`.
4. Ввести **отображаемое имя** — его человек увидит в шапке чата и в списке контактов. Например: `Портал СККИ`.
5. В ответ придёт **токен**. Это пароль бота.

### 3. Передать данные

| Что | Секретность | Куда |
| --- | --- | --- |
| имя бота | открыто | можно в чат |
| токен | **секрет** | `.local/secrets/max-bot.private.txt` |

Ключи в `.env` будут называться `MAX_BOT_USERNAME` и `MAX_BOT_TOKEN`. Как и с Telegram: в git, во frontend и в логи токен не попадает.

### 4. Что будет дальше и чего ждать не надо

**Бот не может написать первым.** Это устройство всех мессенджеров, а не наша недоработка: человек должен сам открыть бота и нажать «Старт», и только после этого портал сможет ему написать. Поэтому в личном кабинете рядом с галочками уведомлений появится ссылка на бота — без этого шага галочки останутся без действия.

Практическое следствие: **уведомления получат только те, кто сам подписался.** Это же и есть согласие на получение персональных данных в мессенджер — по решению владельца от 11.08.2026 содержимое присылается как есть, без нейтральных формулировок.

### Если токен утёк

Перевыпустить у `@MasterBot` и сказать — заменю в `.env`. Подписки людей при этом не теряются: они хранятся по идентификатору человека в MAX, а он от токена не зависит.

## Источники

Порядок создания бота проверен по публичным описаниям MAX Bot API, август 2026: [messangermax.ru](https://messangermax.ru/o-messendzhere/api/), [planermax.ru](https://planermax.ru/docs/create-bot.html). Официальный портал разработчика — [dev.max.ru](https://dev.max.ru/docs-api); раздела о регистрации ботов там нет, вход в портал — через VK ID.
