# HR Domain / Кадровый контур

## Назначение

HR Domain описывает сотрудников колледжа и кадровые состояния, не заменяя Person Foundation. `Person` остается центральной сущностью человека, а `Employee` является кадровым профилем. Один и тот же Person может одновременно быть Employee и Teacher.

## Основные сущности

### Employee

Кадровый профиль человека. Хранит табельный номер, статус, тип занятости, даты приема и увольнения, основное подразделение, должность, ставку и признак `is_teacher`.

Связи:
- `person_id` -> Person;
- `primary_department_id` -> Department;
- `primary_position_id` -> Position;
- через `person_id` может быть связан с Teacher;
- используется Schedule Engine для read-only предупреждений о недоступности преподавателя.

### Department

Подразделение колледжа: учебная часть, отдел кадров, отделение, администрация. Поддерживает иерархию через `parent_id` и признак активности.

### Position

Должность сотрудника. Содержит код, название, категорию и признак активности.

### EmployeeAssignment

История назначений сотрудника: подразделение, должность, тип занятости, ставка, даты действия, приказ и комментарий. Основное назначение синхронизирует основное подразделение/должность Employee.

### EmployeeStatusPeriod

Период кадрового статуса: отпуск, больничный, командировка, отстранение, увольнение и другие состояния. Статус вычисляется по дате, поэтому будущий отпуск не делает сотрудника недоступным до начала периода.

## Статусы

Поддерживаются статусы: `candidate`, `active`, `probation`, `vacation`, `sick_leave`, `maternity_leave`, `business_trip`, `suspended`, `dismissed`.

Для расписания недоступными считаются: `vacation`, `sick_leave`, `maternity_leave`, `business_trip`, `suspended`, `dismissed`.

## Типы занятости

Поддерживаются: `full_time`, `part_time`, `internal_part_time`, `external_part_time`, `contract`.

## Интеграция с Person и Teacher

Employee не копирует личность. ФИО, фото и контакты берутся из Person. Если Person связан с Teacher, карточка сотрудника показывает быстрые переходы к преподавателю, расписанию и нагрузке.

## Интеграция с расписанием

Schedule Engine не отменяет занятия автоматически. Если преподаватель на дату занятия недоступен по кадровым данным, preview расписания возвращает warning `teacher_hr_unavailable` с текстом «Преподаватель недоступен по кадровым данным».

## Импорт

Универсальный импорт поддерживает тип `employees`. Ключ обновления: табельный номер. Person сопоставляется по СНИЛС, email, телефону или ФИО + дата рождения. Неоднозначные совпадения не объединяются автоматически.

## HR-001B: календарь отсутствий

EmployeeStatusPeriod расширен отдельным lifecycle `period_status`: planned, active, completed, cancelled. Добавлен foundation `HrEvent` для будущих уведомлений. Календарь отсутствий показывает периоды, затронутые занятия и связи с заменами преподавателей.
