# Проверка подлинности документов

Публичная проверка доступна по маршруту:

```text
/verify/document/{publicId}
```

API:

```text
GET /api/public/documents/{publicId}/verify
```

Публично показываются только:

- тип документа;
- регистрационный номер;
- дата выдачи;
- маскированное ФИО;
- организация;
- статус;
- дата проверки.

Не показываются дата рождения, адрес, телефон, паспорт, СНИЛС, внутренние ID и полный payload документа.

Статусы:

- `issued` отображается как `действителен`;
- `cancelled` отображается как `отменен`;
- `superseded` отображается как `заменен`;
- `generated` и другие невыданные состояния отображаются как `не выдан`.

Публичный endpoint ограничен rate limit `30 запросов в минуту`.
