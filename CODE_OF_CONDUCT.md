# Code of Conduct

CollegePortal work should remain professional, respectful and focused on building a safe system for college users.

Expected behavior:

- communicate clearly and respectfully;
- document decisions that affect architecture, data or operations;
- protect personal data and credentials;
- raise security and privacy concerns early;
- avoid blame when fixing defects.

Unacceptable behavior:

- exposing secrets or personal data;
- bypassing access controls;
- using production data without explicit authorization;
- harassment, insults or discriminatory language.

Project maintainers may restrict repository access for behavior that risks users, data or project safety.
