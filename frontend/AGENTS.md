# Frontend: локальные правила

- Использовать Vue 3, Quasar, Pinia и существующие компоненты UI Foundation/Design System.
- Не создавать параллельную дизайн-систему и не дублировать общие компоненты без причины.
- Строить routes, меню и действия по permissions; API остается источником истины.
- Показывать inline validation и русские понятные ошибки рядом с полем или действием.
- Все пользовательские подписи писать по-русски.
- Проверять loading, empty, error и forbidden states.
- Для UI-изменений добавлять или актуализировать Playwright-сценарий.
- Проверять desktop `1366x768`, desktop `1920x1080` и mobile `390x844`.
- Не включать credentials и ПДн в fixtures, traces, screenshots и console diagnostics.
- Сохранять существующие маршруты и адаптивное поведение, если задача явно не требует изменения.
